# Project Structure

| Directory | Responsibility | Key Files |
| --- | --- | --- |
| `programs/fructus/src/` | On-chain Anchor program (yield oracle + market + settlement data) | `lib.rs`, `state.rs`, `exchange.rs`, `ed25519.rs` |
| `publisher/` | Off-chain TypeScript keeper (fetch → sign → submit) | `src/index.ts`, `src/update.ts`, `src/message.ts` |
| `trident-tests/` | On-chain stateful fuzz harness (separate workspace) | `fuzz_0/test_fuzz.rs` |
| `docs/` | Documentation | `README.md` (hub) |
| `target/` | Cargo build artifacts (gitignored) | — |
| `.review/` | Review/simplify verdict artifacts (gitignored) | — |

## On-chain program (`programs/fructus/src/`)

| File | Responsibility |
| --- | --- |
| `lib.rs` | Instruction entrypoints + account contexts |
| `constants.rs` | APY/funding scale, domain separators, PDA seeds, validation bounds |
| `state.rs` | `YieldOracle` + `PerpMarket` accounts + pure logic (`is_stale`, `update_message`, validators, …) |
| `exchange.rs` | Trustless settlement: stake-pool exchange rate + realized yield |
| `ed25519.rs` | Publisher signature verification via instruction introspection |
| `error.rs` | `FructusError` error codes |
| `tests.rs` | Property-based + mock-sysvar integration tests |

## Publisher (`publisher/`)

| File | Responsibility |
| --- | --- |
| `src/index.ts` | Keeper main loop (poll + change detection) |
| `src/update.ts` | Build/sign/submit `ed25519 verify` + `update_apy` transaction |
| `src/message.ts` | Canonical message + Anchor discriminator (must match on-chain) |
| `src/jito.ts` | Fetch jitoSOL APY from Jito API + scale to fixed-point |
| `src/state.ts` | Decode on-chain `YieldOracle` + `isStale` mirror |
| `test/message.test.ts` | Cross-language vector + scaling/staleness unit tests |

## Fuzz (`trident-tests/`)

| File | Responsibility |
| --- | --- |
| `fuzz_0/test_fuzz.rs` | Stateful fuzz target (hand-written) |
| `fuzz_0/types.rs`, `fuzz_accounts.rs` | **Generated by `trident init` — do not edit** |
| `Trident.toml` | Program address + `.so` path for the fuzz runtime |

## Config Entry Points

- `Cargo.toml` — Rust workspace manifest (deps, profiles)
- `Anchor.toml` — Anchor workspace config (program id, scripts)
- `publisher/package.json`, `publisher/tsconfig.json`, `publisher/.env.example`
- `trident-tests/Trident.toml`
